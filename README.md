# AFORE

**Before us, nature existed.**

AFORE is a natural art archive exploring the relationship between people and nature through butterfly specimens, visual records, and quiet editorial presentation.

This repository contains the public static website for **aforeart.cn**.

## Pages

- `index.html` - Brand landing page
- `butterflies.html` - Butterfly classification archive
- `butterflies/story.html` - Individual butterfly story page
- `assets/` - Local image assets
- `preview.css` - Shared visual system and layout styles

## Publishing

This site is designed for Cloudflare Pages.

Recommended Cloudflare Pages settings:

- Framework preset: `None`
- Build command: leave empty
- Build output directory: `/`

## Brand

AFORE, or `先在`, begins with the idea that nature existed before human observation. The website presents butterfly specimens not as products, but as records of time, form, color, and encounter.
