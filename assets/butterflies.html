Butterfly Classification

蝴蝶分类档案

AFORE 将蝴蝶视作自然档案，而非装饰符号。本页依据补全图鉴整理 65 个条目，只保留名称、分类、外观特征与图像；价格、利润和报价信息均已移除。

Images are local assets extracted from the supplied Word atlas. Commodity prices and quotation formulas are intentionally excluded from this public archive view.

Class 01

蛱蝶类

蛱蝶常以强烈色块和复杂斑纹建立识别感，红、蓝、白与暗色边缘交织，像自然在翅面上留下的图像笔记。
AFORE-BF-001

血漪蛱蝶

猩红翅面近乎纯色，暗色翅缘收住火焰般的张力。
AFORE-BF-009

蓝带绒蛱蝶

暗色翅面横贯蓝带，冷色带纹成为最醒目的识别线。
AFORE-BF-011

美丽彩袄蛱蝶

橙红斑块明亮跳跃，黑色边线像把色彩缝在翅上。
AFORE-BF-013

淡绿无鳌蛱蝶

淡绿色调安静铺开，边缘细暗，气质像潮湿苔痕。
AFORE-BF-015

蓝带鸭蛱蝶

蓝带嵌在深色底面中，像一条冷光穿过绒面。
AFORE-BF-016

锯纹白斑蛱蝶

白斑与锯齿状暗纹交错，边缘带有清晰的节奏。
AFORE-BF-019

玫瑰袄蛱蝶

玫红与深色相互压低，鲜艳中保留一种暗调华丽。
AFORE-BF-022

印尼文蛱蝶

纹理层次如异地文字，斑块在翅面上形成阅读感。
AFORE-BF-023

蛤蟆蛱蝶

褐色肌理厚重，斑纹粗砺，带有林地伪装的质感。
AFORE-BF-034

红矩蛱蝶

红矩形斑块清晰有力，像被自然盖下的一枚朱印。
AFORE-BF-038

斑蛱蝶

斑纹分布复杂，色块像自然形成的小型拼贴。
AFORE-BF-052

翠丽斑蛱蝶

翠绿斑块在暗面中浮现，细碎而有宝石感。

Class 02

闪蝶类

闪蝶的美来自结构色：蓝、银、紫与青绿并非静止颜料，而是随光线角度变化的冷色反射。
AFORE-BF-002

安东尼斯

淡蓝至银紫的半透明光泽，翅尖覆有褐色阴影。
AFORE-BF-004

梦幻

深蓝金属光铺展，暗色外缘让蓝色更显沉静。
AFORE-BF-005

西风

湖蓝与青绿交叠，前翅白斑像风穿过海面的亮点。
AFORE-BF-007

海伦

银蓝光泽强烈，翅面在冷白与金属蓝之间转换。
AFORE-BF-008

夜明珠

珍珠白底透出蓝紫虹彩，像夜色里微微发光的贝母。
AFORE-BF-065

大蓝闪蝶

大翼展铺开纯净金属蓝，深褐翅缘像蓝色镜面的边框。

Class 03

蝶类

这一组保留更开放的蝶类档案，色彩、形态与命名来源较杂，像自然收藏中尚待细读的边页。
AFORE-BF-003

肯特白

乳白翅面配深色细边，像纸页上留下的轻微墨痕。
AFORE-BF-037

蓝草德

蓝绿宽带浓郁，黑色背景衬出金属般的冷光。
AFORE-BF-040

珍蝶

体态小而精致，翅面细节像珍珠表面的微光。
AFORE-BF-045

国产杂蝶

综合色斑自然错落，带有野外采集记录的原生感。
AFORE-BF-053

纯帛斑蝶

帛质般的浅色翅面，斑纹轻柔，气质安静含蓄。
AFORE-BF-057

绿带春

黑底上铺开亮绿色带纹，长尾与蓝绿边斑让春意更锋利。

Class 04

蛾类/大蚕蛾类

蛾类与大蚕蛾具有更夜性的体量感，宽阔翅面、羽状触角与长尾让它们接近静默的夜间器物。
AFORE-BF-006

太阳蛾

黑底上有太阳般的彩色斑纹，尾突细长而具有仪式感。
AFORE-BF-010

月亮

浅绿或月白色调，长尾与眼斑让轮廓接近月光。
AFORE-BF-025

王氏大蚕蛾

大翅面与羽状触角突出，整体像夜间展开的植物。
AFORE-BF-026

冬青大蚕蛾

青绿色夜蛾气质，宽翅与柔暗边缘形成静默体量。
AFORE-BF-030

波带锦燕蛾

波状带纹与长尾共同展开，带有燕蛾特有的飘逸感。
AFORE-BF-033

明目大蚕蛾

大蚕蛾式宽阔翅面，眼状斑让静止姿态带有注视感。
AFORE-BF-046

彗星尾大蚕蛾

彗星般长尾极具辨识度，翅面宽大而线条飘逸。

Class 05

眼蝶类

眼蝶以环状眼斑形成独特的“回望”，图案既是伪装与防御，也是翅面上最具戏剧性的视觉中心。
AFORE-BF-012

黄晶眼

黄晶色透明感与圆形眼斑并存，轻盈而带警觉。
AFORE-BF-014

玫瑰俏眼蝶

透明翅面染玫瑰色，眼斑细小，像玻璃上的花影。
AFORE-BF-018

眼环蝶

环状眼斑排列清楚，像一组沉默的回望。
AFORE-BF-059

优雅眼蛱蝶

蓝紫翅面配眼斑结构，优雅中带一点戏剧性。

Class 06

凤蝶类

凤蝶重在线条与姿态：尾突如笔锋，黑色轮廓托起翠绿、白、黄与蓝色斑带，带有飞行后的余势。
AFORE-BF-017

手掌美凤蝶

翅形宽展似手掌，尾突轻收，姿态柔和而庄重。
AFORE-BF-020

木兰青凤蝶

青黑翅面修长，尾突如笔锋收束，线条清雅。
AFORE-BF-021

蓝带青凤蝶

蓝色带纹穿过黑翅，尾突拉长飞行的方向感。
AFORE-BF-024

鹅黄凤蝶

鹅黄色明净，黑色脉纹与尾突让轮廓更加挺拔。
AFORE-BF-028

宽尾翡翠凤蝶

翡翠色金属光集中，宽尾让后翅显得稳定而厚重。
AFORE-BF-029

五斑翠凤蝶

黑底上分布五处翠斑，尾突清晰，像古玉嵌在夜色中。
AFORE-BF-031

玫瑰青凤蝶

青黑底色衬托玫瑰斑，尾端线条细长而锋利。
AFORE-BF-032

白裙美凤蝶

白裙状后翅醒目，黑色外缘让白色更显干净。
AFORE-BF-035

白翠凤蝶

白翅中带翠色光泽，凤蝶尾突使整体更显东方气息。
AFORE-BF-036

绿斑德凤蝶

绿色斑带嵌入黑翅，明暗对比清楚，轮廓修长。
AFORE-BF-039

马达加斯加达摩凤蝶

达摩凤蝶轮廓挺括，尾突下垂，带岛屿物种的异域感。
AFORE-BF-047

雌白裙美凤蝶

雌蝶白裙更为柔和，暗色边缘像衣褶的收口。
AFORE-BF-054

印尼产卡尔娜翠凤蝶

黑翅深沉，后翅有青绿光斑与玫红眼纹，尾突修长。
AFORE-BF-055

斑凤蝶

斑纹与凤蝶尾突并存，像一段被展开的飞行记号。
AFORE-BF-058

丽长尾绿凤蝶

褐黑前翅配白色斜带，后翅长尾极长，线条像被拉远的风。
AFORE-BF-061

巨美凤蝶

体型较大，凤蝶轮廓舒展，整体有庄重的收藏感。
AFORE-BF-062

天堂凤蝶

黑翅中央带宝石蓝区域，像夜色中开启的天窗。

Class 07

蚬蝶类

蚬蝶体量较小却色彩紧凑，红斑与绿带在暗面中闪现，像被压缩进微小尺度的宝石光。
AFORE-BF-027

红斑绿带蚬蝶

绿带与红斑并置，像暗色底面上浮出的宝石火星。

Class 08

粉蝶类

粉蝶以白、乳黄与浅褐翅脉建立留白感，细小斑点和柔薄质地让它们更接近纸、光与空气。
AFORE-BF-041

越南完善绢粉蝶

绢粉质感轻薄，白色翅面有一种半透明的安静。
AFORE-BF-042

黑脉园粉蝶

黑色翅脉清晰铺开，像在白纸上画出的植物分枝。
AFORE-BF-043

卡利善索粉蝶

浅色粉蝶气质干净，边缘与斑点让轮廓保持秩序。
AFORE-BF-048

大菜粉蝶

大面积白翅朴素明净，黑点与翅尖构成轻微停顿。
AFORE-BF-049

棕脉粉蝶

棕色翅脉温和可见，给浅色粉蝶添入木质感。
AFORE-BF-050

鹤顶粉蝶

前翅橙红顶端鲜明，像白色翅面上点起的鹤顶。
AFORE-BF-051

菜粉蝶

白色翅面简洁轻小，带有田野中最日常的明亮。
AFORE-BF-056

小檗斑粉蝶

小型粉蝶带斑点节奏，轻盈但不单薄。
AFORE-BF-060

印尼红翅鹤顶

红翅与粉蝶的洁白对比强烈，像清晨的一点暖光。

Class 09

灰蝶类

灰蝶通常尺度更小，色调克制而细节密集，需要靠近观看，才能辨认柔灰、蓝光与细斑之间的差异。
AFORE-BF-044

国产灰蝶

灰蓝小型翅面低调，细斑与柔色适合近距离观看。
AFORE-BF-063

蛾娆灰蝶

灰蝶小巧而带蛾感，色调收敛，适合安静观看。
AFORE-BF-064

优雅灰蝶

灰蓝色调柔和，翅面细腻，优雅感来自克制的尺度。
